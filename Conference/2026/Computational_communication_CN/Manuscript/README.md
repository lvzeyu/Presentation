# SSM Workshop Extended Abstract

English extended abstract based on the materials in `Conference/2026/SSM_workshop`.
The manuscript is intentionally anonymous: it contains no author, affiliation, correspondence, date, or author PDF metadata.

The visual design follows `Abe_Twitter_Manuscript`: classic blue headings,
Springer-style typography, a single-column review layout, double spacing,
one-inch margins, and first-line paragraph indentation.

All prose and the APA 7 reference list are contained in `main.tex`; the title and keywords are in `paper-config.tex`. Because the document is itself an extended abstract, it has no separate abstract block. The project does not use a `secs/` directory.

Run `make` to generate `main.pdf` with LuaLaTeX, `make watch` for continuous compilation, or `make clean` to remove build products.
